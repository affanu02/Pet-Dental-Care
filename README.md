# Pet Dental Care

A friendly guide to dental care for dogs and cats.

## Development

You need Node.js and Bun installed.

```sh
git clone <this-repository-url>
cd Pet-Dental-Care
bun install
bun run dev
```

The local development server is available at `http://localhost:3000`.

Useful commands:

```sh
bun run build
bun run preview
bun run lint
bun run test
```
